# Development history

This is a scientific and engineering chronology, not a replacement for the private pre-public commit log.

| Milestone | Purpose and methodological advance | Verified status |
| --- | --- | --- |
| Raw recording inspection | Established channel layout, sampling rate, annotations, and recording-boundary behavior. | Complete |
| Signal quality and spectral analysis | Added recording checks, task/rest comparisons, and interpretable sensor-level time-frequency measures. | Complete |
| Epoching and QC | Fixed event windows and label-independent trial-quality checks before model evaluation. | Complete |
| PhysioNet cohort replication | Extended the sensor-level replication to the predeclared cohort with technical exclusions documented separately from outcomes. | Complete / frozen |
| Individualized-frequency work | Tested a rest-derived individualized-mu extension and documented its reliability and held-out comparison. | Secondary / complete |
| Within-subject decoding | Evaluated CSP+LDA and a spectral baseline using leave-one-run-out predictions and fit audits. | Complete / frozen |
| Leakage and reliability audits | Added source/hash validation, trial-level fit audits, and run/QC sensitivity checks. | Complete |
| Transfer and calibration | Added strict zero-shot, limited target calibration, spatial, and Riemannian secondary studies with frozen development/final boundaries. | Secondary / complete |
| External cross-session protocol | Specified Lee2019/OpenBMI source validation and cross-session evaluation without inspecting external outcomes. | In progress — not yet evaluated |
| Public-release hardening | Added licensing, citation, portable provenance, regression checks, and a sanitized public baseline. | Complete |

Exploratory work remains labelled as exploratory. Completed results are not converted into confirmatory claims merely because they are preserved here.
