# Historia de desarrollo

Esta cronología científica y de ingeniería no reemplaza el registro privado de *commits* previo a la publicación.

| Hito | Propósito y avance metodológico | Estado verificado |
| --- | --- | --- |
| Inspección de registros | Estableció canales, frecuencia de muestreo, anotaciones y límites de cada registro. | Completo |
| Calidad y espectro | Incorporó controles de señal y medidas tiempo-frecuencia a nivel de sensor. | Completo |
| Épocas y QC | Fijó ventanas por evento y controles de calidad independientes de las etiquetas. | Completo |
| Replicación PhysioNet | Extendió la replicación al grupo predefinido con exclusiones técnicas documentadas. | Completo / congelado |
| Frecuencia individualizada | Evaluó una extensión de mu individual derivada del reposo. | Secundario / completo |
| Decodificación intra-sujeto | Evaluó CSP+LDA y una línea base espectral con *runs* retenidos. | Completo / congelado |
| Auditorías | Añadió auditorías de fuga, procedencia y sensibilidad a QC. | Completo |
| Transferencia y calibración | Añadió estudios secundarios zero-shot, calibración, espacial y Riemanniano. | Secundario / completo |
| Protocolo externo | Especificó Lee2019/OpenBMI sin inspeccionar resultados externos. | En progreso — aún no evaluado |
| Preparación pública | Añadió licencia, citación, procedencia portátil y una base pública saneada. | Completo |

El trabajo exploratorio conserva esa etiqueta; esta historia no lo convierte en evidencia confirmatoria.
